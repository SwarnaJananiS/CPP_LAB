# C++ Programming Lab Experiments

This repository contains 13 C++ programming lab experiments covering fundamental and advanced C++ concepts, Object-Oriented Programming, STL, memory management, multithreading, and modern C++ features.

## Experiments


| 1 | University Management System Using Encapsulation, Constructors and Destructors |
| 2 | Runtime Polymorphism Using Virtual Functions and Abstract Classes |
| 3 | Matrix Operations Using Operator Overloading |
| 4 | Stack and Queue Implementation Using Templates and Performance Comparison with STL |
| 5 | Student Grade Analyzer Using STL Algorithms and Lambda Expressions |
| 6 | Smart Pointer Implementation Using RAII, `unique_ptr` and `shared_ptr` |
| 7 | Exception Safety in Bank Account System Using Custom Exception Classes |
| 8 | Move Semantics and Perfect Forwarding for Resource-Heavy String Class |
| 9 | Singleton, Factory and Observer Design Patterns for Event-Driven Notification System |
| 10 | Multithreaded Producer-Consumer System Using Mutex and Condition Variables |
| 11 | Type-Safe Unit Conversion Library Using Templates and `constexpr` |
| 12 | Mini File System Simulator Using File I/O Streams and Binary Serialization |
| 13 | Generic Data Pipeline Using C++20 Modules, Concepts and Ranges |

## Technologies Used

- C++
